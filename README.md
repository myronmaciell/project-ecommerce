# E-commerce Java + React

E-commerce full stack desenvolvido para estudos e portfólio utilizando Java, Spring Boot, React, PostgreSQL e Stripe.

## Tecnologias

### Backend
- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- Vite
- JavaScript

### Integrações
- Stripe
- Serviço de e-mail

### Infraestrutura
- Docker
- GitHub Actions

## Funcionalidades

- Autenticação
- Autorização por perfil
- Cadastro de usuários
- Catálogo de produtos
- Carrinho de compras
- Pedidos
- Pagamentos com Stripe
- Webhooks
- Envio de e-mails
- Área administrativa
